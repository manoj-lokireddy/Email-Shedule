# Email Scheduler Visual Assets

The `screenshots` folder contains the captured login surface. Open `showcase.html` in a browser and choose **Print -> Save as PDF** to create or refresh `email-scheduler-showcase.pdf`.

## Assets

- `screenshots/login.png`: live login screen capture
- `showcase.html`: print-ready project showcase
- `email-scheduler-showcase.pdf`: PDF export target for GitHub/demo sharing

The showcase explains the complete flow: React dashboard -> Express API -> PostgreSQL/Prisma -> Redis/BullMQ -> worker -> SMTP -> Elasticsearch.
